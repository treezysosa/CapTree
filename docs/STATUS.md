# Version 0.5 boundaries and verification

This repository implements a native, installable Android MVP. The feature names reflect the product cartridges; conventional algorithms are labeled in the UI.

## Implemented

* Offline photo correction (brightness/exposure/contrast/color/white balance/saturation), denoising, sharpening, 2048-pixel decode cap, JPEG quality or lossless PNG export, original/result switching and zoom.
* Local Real-ESRGAN RGB float32 ONNX x4 inference with 64-pixel tiles / 16-pixel halos; x2 from the x4 result. Model and RAM checks, real on-device inference probes before installation, a repeatable Settings self-test, and model SHA-256 diagnostics; no bicubic-only AI fallback.
* Editable Media3 clip timeline with per-block trims, split at playhead, add/remove/reorder controls, synchronized H.264/AAC merge (including silent clips), 9:16/1:1/16:9 crop, timed caption overlays, and editable SRT import/export. Captions follow source ranges through timeline edits; retained source cues restore hidden text when a trim expands. Media3 uses the device codecs and GPU effects.
* Histogram scene-change suggestions at one-second intervals; PCM quiet-audio timestamps. Automatic clip-range suggestions rank scene changes, quiet audio and existing captions, show the measured reasons, and apply the selected range. These are conventional heuristics, not semantic AI highlight selection. Range scans support a selected clip of up to two minutes.
* Video enhancement: brightness, contrast, saturation, edge-aware spatial GPU denoising, unsharp-mask sharpening, and translation-only stabilization. Stabilization measures motion at 10 Hz, smooths the path and crops borders; strength controls smoothing and up to 1.22× zoom. It needs a textured, mostly static background and a source of at most two minutes. It does not correct rotation or rolling shutter. Photo comparisons offer original/result switching plus a draggable wipe with shared zoom. Video exports tone-map HDR to SDR.
* GIF from images/video with frame selection, 1–24 FPS, speed, captions, stickers, loop flag and dimensions. Real GIF89a, classic RGB332 or adaptive per-frame palettes with up to 64/128/256 colors, optional Floyd–Steinberg dithering, dictionary-based LZW compression and bounded-memory blocks. Smaller dimensions/FPS often reduce size; dithering can increase it. Maximum 240 frames. One-shot previews stop at the last frame and can restart. MP4 mode shares captions, stickers, dimensions and speed controls; video audio changes speed with the picture. Image sequence MP4 supports an effective rate (FPS × speed) of at most 60 FPS. Video FPS is a frame-dropping cap, without motion interpolation. The loop flag belongs to GIF; MP4 playback looping is controlled by the player. Mixed image sizes are letterboxed without stretching.
* Optional real Stable Diffusion / CogVideoX inference, secure job API, hardware/package readiness reports, model callbacks, result export and cancellation. Unloaded models are distinguished from supported hardware and loaded pipelines. Models must be obtained under their licenses.
* Automatic subtitles via the optional faster-whisper server: explicit audio-upload confirmation, selected-range PCM WAV extraction on the phone, CPU speech inference, editable/exportable SRT results, and applying captions to the saved timeline snapshot. Only the selected audio is uploaded; video frames and local project paths are excluded. Requires backend v0.3 / API v2 and remote consent.
* Project rename/duplicate/delete/favorite/resume; generation history and gallery filtering; three themes; sounds/haptics; cleanup; consent and Keystore token. Editor undo/redo retains up to 30 in-memory steps and protects referenced imports during cleanup. Enhanced videos offer linked side-by-side previews with a shared playhead and original audio.

## Not implemented / practical limits

* Face restoration, semantic highlight scoring, and automatic on-phone speech transcription require additional models or processing implementations. The UI states those limits. Speech recognition currently runs on a user-owned server or through the optional local-PC faster-whisper CLI; on-phone speech inference is not included.
* Trim/split is based on time; D-pad seeks the selected preview in 1/30-second steps, not guaranteed exact source-frame boundaries for variable-FPS media. Timeline blocks use explicit move-left/right controls. Captions follow their source clip; manual caption edits establish a new source from the current trim. Review phrase boundaries after cuts; word-level alignment is not included. SRT supports up to 2000 cues/fragments; invalid timestamps are rejected. Undo history resets on project open/resume and app restart. Linked preview periodically corrects drift and can fall back to single playback if a device cannot decode both streams; it is not guaranteed frame-accurate synchronization.
* ONNX input must be dynamic spatial size or fixed 96×96, float32 `[1,3,H,W]`; output x4 RGB float32 NCHW. Phone input is sampled to at most 1024 pixels. RAM checks can reject much smaller sources on low-memory phones. No model download runs without your action.
* CogVideoX generates 49 native frames (roughly six seconds at 8 FPS); output is trimmed and center-cropped/resized. Motion slider changes descriptive prompt wording. Image-to-video uses the separate CogVideoX-5b-I2V model. GPU required for video. No claim that these models work on every phone.
* Local jobs use WorkManager's normal ten-minute execution window. Remote polling times out at eight minutes and requests cancellation/purge. Preload models; cold downloads can exceed that window. Server cancellation is checked between diffusion steps and after loading; it cannot interrupt an individual GPU kernel.
* Minimum Android 8; modern Photo Picker falls back to the system document picker where unavailable. 512 MB import/file, 12 MB server image upload, ten minutes / 64 MB per selected subtitle audio upload, 1 MB subtitle download, 200 MB generated media download. GIFs are intentionally bounded for memory/storage.

## Verification policy

CI runs JVM encoder/timeline/caption/motion/range/history/palette tests, Android lint, APK compilation, backend API tests, and Android 10/API 29 plus Android 15/API 35 emulator tests. Instrumentation exercises real photo correction, animated GIF decoding, the import/WorkManager/Room workflow, audio/video trim/merge/crop, caption rendering, GPU shader export, and UI split/reorder controls. Phase 4 added checks for compressed GIF decoding and one-shot playback, encoded MP4 styling, speed-adjusted audio/video timing, reduced jitter on original synthetic footage, and applying scanned clip ranges through the UI. Phase 5 adds adaptive color decoding, caption-retiming/undo UI checks, retained-caption recipes, incomplete-trim rejection, and linked playback of an original and genuinely enhanced video. Separate pretrained-model checks have successfully run official Real-ESRGAN x4plus through PyTorch/ONNX numerical comparison and Android output comparison, Stable Diffusion 1.5 at 512×512 / 24 CPU steps, and faster-whisper tiny on generated test speech. These are actual model executions, not the protocol test doubles. CUDA video generation and physical-phone testing remain unvalidated. The app requires real model files and an operator-owned inference host for AI generation; production code never synthesizes placeholder results.
