# Privacy

The app has no account system, advertisements, analytics, tracking SDKs, paid APIs, or watermarking. Android backup is disabled. Selected imports are copied to private app storage; Room stores recipes and project metadata locally. Conventional editing and on-device ONNX processing do not use the network.

Remote generation is off by default. The operator saves an HTTPS URL and token and enables the clearly labeled remote-processing toggle. Changing the URL revokes consent. Starting a remote creation sends only allowlisted prompt/settings and an optional image to that specific server; local paths and tokens are excluded from payload JSON. Automatic subtitles require an additional Send Audio confirmation and upload only the selected clip's trimmed audio, decoded locally to PCM WAV. Video frames and other timeline clips are not uploaded for transcription. Tokens use Android Keystore AES-GCM. HTTP, invalid certificates, credential-bearing URLs, and redirects are rejected. No hardcoded API secrets.

Optional face restoration is also off by default. It runs on the configured self-hosted CPU server, after local enhancement/upscaling. Both touch and virtual-A actions require a separate Send Processed Photo confirmation. The request contains only the processed PNG and restoration strength; project paths, captions and other recipe metadata are excluded. The worker checks consent and the configured server again before any upload. A retry requires confirmation again. Local enhancement without this option never uploads the photo.

The optional server requires a bearer token, bounds uploads and queued jobs, validates images, uses generated UUID directories rather than supplied file paths, deletes image/audio uploads after inference, and honors cancellation and result purge requests. Completed jobs expire after 24 hours if not purged sooner. Android purges remote results after download. Server operators control their own infrastructure, firewall, model cache, and access logs. Use one backend instance per trusted user/group; the shared token is not multi-tenant authentication. Run behind HTTPS and do not expose the unauthenticated Uvicorn socket to the public Internet.

Save to Gallery, Export File, and Share are explicit user actions. Deleting an app project removes its private output; copies already exported/shared remain outside the app's control. Clear cache removes unused imports referenced by no saved or open project. Uninstall removes private app data and Keystore credentials.

Portable project backups are explicit document-picker exports. They include selected project media, outputs, captions and editing parameters, but exclude backend URLs/tokens, work IDs, remote-upload consent and model weights. They are not encrypted. Import validates asset sizes/hashes and safe entry names, restores new private files and a new Room record, and disables face restoration in the imported recipe. It does not start remote processing or replace device connection settings. Incomplete staging data is removed on failure/cancellation or the next app startup after a process interruption. Keep the completed ZIP outside private app storage if you need it after uninstalling.

Optional CLIP highlights require a separate **Send Selected Frames** confirmation tied to the saved trim, description and target server. Up to 24 re-encoded JPEG thumbnails (256-pixel maximum edge) and relative sample times are sent; audio, full video, source EXIF and project paths are excluded. Thumbnails can still contain private content. Workers recheck consent/target before decoding and upload; retries ask again. The server deletes sampled frames after inference and purges result data on request. Portable backups exclude frame-upload consent but can retain the description and result report.

Offline English subtitles use an explicitly imported Vosk model in private storage. The app checks the pinned archive and native compatibility before installation. The offline worker decodes only the selected local audio, writes temporary PCM WAV, runs native recognition and saves timed SRT; it never creates a backend client and does not require remote consent. Temporary audio is deleted on completion/failure/cancellation. No microphone permission is used. Models are excluded from portable backups; captions and model provenance can be included. The official model download opens in the browser only when requested.
